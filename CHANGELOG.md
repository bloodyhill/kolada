# Changelog

What changed in each Kolada release, newest first.

## [0.4.4] - 2026-10-29

### Added
- Beam up to 10 pictures at once, and save or copy them all.
- Settings can check for updates now.

### Changed
- Settings › Devices shows each device by a clear name and its own icon, and you can rename this one.
- Beam, menus, panels and the side menu have clearer surfaces and buttons.
- Beam recognises passwords better.

### Fixed
- Paired devices keep their names after you remove one.
- Buttons in Settings read clearly in both themes.

## [0.4.3] - 2026-10-28

### Added
- Beam: send text, links, passwords and pictures between your devices.
- Press Alt+Z to beam what you copied (Option+Z on the Mac).
- Pair your devices once, with a code or by scanning it with your phone.
- Beam stays open as you send, and a check shows when it arrives.
- Click a long beam to read it all, or open it as a note.
- A password you beam is copied once, then leaves the clipboard.
- Sync: your notes stay the same on every device you pair.
- If two devices change a note, the other version is kept in its history.
- Linux: Beam, and the AI writing assistant.

### Changed
- Search stays open while you open its results, and its ✕ ends it.
- New note has a new + icon.

### Fixed
- The AI writing assistant fixes Korean again, and leaves correct Portuguese as it is.
- A saved note keeps the date it was created.
- Note history keeps versions written by a newer Kolada.

## [0.4.2] - 2026-10-26

### Added
- Windows: AI writing assistant. It fixes typos, spelling and grammar as you type in nine languages, and sums up long notes in one line.

### Fixed
- Windows: the side menu pins again after minimal mode.
- Windows: writing help rests while Kolada is hidden, and ending it in Task Manager keeps it ended.

## [0.4.1] - 2026-10-21

### Added
- Linux: the .tar.gz install updates itself, an AppImage, reminders, and New Note and Search on Kolada's icon.

### Changed
- Mac: typing redraws only what changed, and Kolada opens as fast as an empty Mac window.

### Fixed
- Linux: input methods type each word once.
- Linux: PDF export works where the browser's sandbox can't start.

## [0.4.0] - 2026-10-21

### Added
- Kolada for Linux, as a .deb and a .tar.gz.
- The Mac app catches up with Windows: clean editing, share links, links with ⌘K, reminders and the writing-model choice.
- The Mac app updates itself.
- Word, PDF and web pages dropped on the Mac become notes.

### Fixed
- A folder opened with Kolada on Windows opens as the vault.

## [0.3.1] - 2026-10-15

### Fixed
- Writing help now arrives with updates.

## [0.3.0] - 2026-10-15

### Added
- Notes show their formatting without Markdown symbols.
- Share a note as a link.
- Ctrl+K links words to a note or a page.
- A formatting bar over selected text.
- Seven text sizes.
- Choose a writing model on first run.

### Changed
- The toolbar stays hidden until you need it.
- Related notes start off.

### Fixed
- Emoji draw in colour on Linux.

## [0.2.0] - 2026-10-14

### Changed
- Notsy is now **Kolada**, at [kolada.app](https://kolada.app).
- A new look, with a teal accent and a graphite dark theme.
- The Mac app is signed and notarized.

### Fixed
- Writing help starts right away again.
- Reminders arrive on time.

## [0.1.1] - 2026-10-11

### Added
- A new installer.
- The first Mac beta, for Apple silicon.

## [0.1.0] - 2026-10-10

### Added
- Install from the website, with automatic updates.

## [0.0.1] - 2026-10-10

### Added
- The first release, in the Microsoft Store.
