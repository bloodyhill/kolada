# Parity ledger

Every feature of Notsy, where its code lives, the tests that say what it does, and where each platform stands. Read with [porting.md](porting.md): new work after 2026-10-04 also arrives through `tools/port-queue.sh`.

When you add a feature, add its row. When you port one, mark your column in the same commit.

**Code:** a shared crate (reaches every platform), or the shell (`notsy-win` on Windows: each platform builds its own). The Mac's app state, and the tests written `Mac `model/...``, are in the shared crate `crates/notsy-app/src/model/` (headless: any shell drives it; each OS's calls come in through `notsy_app::services`); what stays in `crates/notsy-mac/src/mac/` is the AppKit shell and the Mac's implementations of those services (`spell.rs`, `vision.rs`, `watch.rs`, `web.rs`, `bin.rs`, `when.rs`, `images.rs`, `fonts.rs`).
**State:** ✅ done · ◐ shared: its shared code builds and passes its tests there, the platform's own part is not built yet · — not yet · n/a does not apply.
