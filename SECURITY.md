# Security

## Supported versions

Only the latest release gets security fixes. The website's version and the Microsoft Store version update themselves; the Mac beta is updated by downloading the newest DMG.

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| Older | No |

## Reporting a vulnerability

Please report it privately through GitHub: on the [Security tab](https://github.com/bloodyhill/kolada/security), choose **Report a vulnerability**. Please don't open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. We aim to answer within a few days, and to ship a fix as soon as it is ready. Reporters are credited in the release notes unless they prefer not to be.

## In scope

- The Kolada apps for Windows, macOS and iOS built from this repository.
- The update check and download (the feed on kolada.app and the checks the app makes on what it downloads).
- The local writing model's process, and the converters that read Word, PDF, HTML and imported notes.

The website itself (kolada.app) and the Microsoft Store are out of scope here; for the Store, report to Microsoft.
